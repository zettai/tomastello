# Accessibility — Scan Live Pages

Run pa11y-ci against the running dev server to check WCAG 2.1 AA compliance.

## Prerequisite

The dev server must be running: `npm run dev`

## Steps

1. Run `npm run a11y` and capture the full output.

2. For each URL scanned, report results in this format:
```
✅ http://localhost:3000 — no issues
❌ http://localhost:3000/login — 2 issues:
   [error] Form elements must have labels (label) — <input type="text" ...>
   [warning] Ensure all text has sufficient colour contrast (color-contrast)
```

3. If issues are found, group them by:
   - **Errors** (must fix — WCAG violations)
   - **Warnings** (should review)

4. Ask if you should fix the errors now.

## Notes

- `/admin` redirects to `/login` without auth — scan `/login` and `/register` instead for auth-gated pages
- `jest-axe` in `npm test` catches violations at the component level automatically; pa11y catches full-page issues including CSS-driven contrast
